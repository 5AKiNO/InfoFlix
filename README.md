## ✨ Características Principales

- 🍿 **UI/UX Inspirada en Netflix:** Paleta de colores `#141414` y `#E50914`, gradientes cinematográficos y tarjetas de episodios.
- 📱 **Diseño 100% Responsivo (Mobile-First):** Se adapta desde teléfonos móviles hasta monitores de escritorio.
- ⚡ **Generación Dinámica con Vanilla JS:** Los módulos ("episodios") y sus ventanas modales se renderizan desde un único array de objetos en JavaScript. Fácil de editar sin tocar el HTML.
- 💬 **Embudo de Conversión a WhatsApp:** Enlaces dinámicos que detectan qué módulo está viendo el usuario y pre-redactan el mensaje de consulta.
- ♿ **Accesible y Ligero:** Navegación por teclado (`Tab`, `Enter`, `Escape`) y sin dependencias pesadas
